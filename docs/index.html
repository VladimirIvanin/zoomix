01

Быстрый старт

Выберите способ подключения. Для обычной HTML-страницы достаточно двух файлов и атрибута на обёртке фотографии.

Соберите проект командой npm run build и скопируйте dist/zoomix.min.js и dist/zoomix.css в ресурсы вашей темы.

HTML · автоматическое подключение
<link rel="stylesheet" href="/assets/zoomix.css">
<script defer src="/assets/zoomix.min.js"></script>

<div data-zoomix="inner" data-zoom-scale="2">
  <img
    src="/products/watch-640.jpg"
    data-zoom-src="/products/watch-2400.jpg"
    width="640" height="480"
    alt="Циферблат часов"
    draggable="false"
  >
</div>

Браузерная сборка сама подключает существующие и добавленные элементы [data-zoomix], а при удалении из DOM освобождает их экземпляры.

В репозитории Zoomix выполните npm pack. Установите полученный архив в проект магазина:

Терминал · в проекте магазина
npm install /путь/к/zoomix-0.1.0.tgz

Создайте обёртку <div id="product-photo"> с одной фотографией внутри и инициализируйте её после появления в DOM.

TypeScript · ручное подключение
import Zoomix from 'zoomix';
import 'zoomix/style.css';

const photo = document.querySelector<HTMLElement>('#product-photo');

if (photo) {
  const zoom = new Zoomix(photo, {
    mode: 'inner',
    scale: 2,
  });

  // При размонтировании компонента: zoom.destroy();
}

ESM-сборка оставляет инициализацию приложению. В браузерной сборке конструктор доступен как window.Zoomix; для ручной настройки используйте обёртку без data-zoomix.

Одна обёртка — одна фотография. Превью и большой оригинал должны показывать одинаковый кадр с теми же пропорциями. Размер фотографии задаёт CSS вашей темы.
02

Режимы увеличения

Выберите режим и наведите курсор на изображение. На сенсорном экране коснитесь его: увеличение всегда откроется внутри кадра.

+

Увеличение внутри фотографии. Подходит для компактных карточек товара.

data-zoomix="inner"

В этом примере sideTarget выводит детали в область с описанием рядом с фото. Без заданной панели окно появляется справа или слева; если места недостаточно, Zoomix переключается на inner. При касании всегда используется inner.

  });

Группы и подписки

Zoomix.get(element) и Zoomix.getScope(root) получают существующие объекты. Методы open(), enable(), disable() и update(patch) управляют фотографией. getState() различает запрос открытия, видимость, загрузку и уничтожение; effectiveMode и effectiveScale показывают фактическое увеличение.

const scope = Zoomix.mount(widgetRoot, {
  selector: '.js-product-zoom',
  options: { mode: 'side', scale: 2 }
});
const off = scope.on('open', event => console.log(event.instance));
scope.close();
scope.destroy();

Группа предоставляет getInstances(), refresh(), update(), close(), enable(), disable(), destroy(), on() и signal. Новые фото подключаются автоматически, удалённые освобождаются. Управляемые фото используют собственный селектор без data-zoomix. У фотографии один владелец. Скрытие сохраняет группу; удаление её корня уничтожает группу.

События: statechange, open, close, loadstart, load, error, destroy; у группы также mount и unmount. Метод on() возвращает функцию отписки и принимает { once, signal }. События фото содержат element, instance и state; группа добавляет scope. Собственный destroy группы не содержит instance. История событий не воспроизводится. Ошибки обработчиков не прерывают очистку.

open означает появление увеличения, close — его скрытие. Сначала приходит statechange, затем соответствующее событие. События загрузки сообщают source, requestedSource и fallback. Устаревшие ответы игнорируются. Сигналы времени жизни прерываются до финального destroy. Внешние подписки InSales привязывайте к scope.signal.

Примеры галереи, AJAX-списка и быстрого просмотра InSales. Полный контракт описан в README репозитория.

04

Методы

Сохраните экземпляр, чтобы управлять его жизненным циклом. Повторный вызов конструктора для той же обёртки возвращает существующий экземпляр.

zoom.close()
Закрывает увеличение. Вызывайте перед сменой слайда или началом перетаскивания галереи.
zoom.refresh()
Заново находит фотографию и обновляет состояние после ручного изменения разметки. Изменения источника и замена фото отслеживаются автоматически.
zoom.destroy()
Закрывает увеличение, отключает обработчики и наблюдатели, восстанавливает атрибуты обёртки. Вызывайте при размонтировании компонента.
05

Оформление

Zoomix поддерживает picture, srcset, object-fit и object-position. Настройте лупу через CSS-переменные на обёртке.

CSS · размер и обводка лупы
.product-photo {
  --zoomix-lens-size: 160px;
  --zoomix-lens-outline: 2px solid #faf9f3;
}

По умолчанию размер лупы — 144px, обводка — 2px solid white. Также доступны --zoomix-background (белый фон), --zoomix-marker (#fff4) и --zoomix-z-index (100).

Автоматическое боковое окно добавляется в body. Для него задавайте CSS-переменные на :root; для sideTarget — на самой панели или её предке.

07

Управление

Мышь
Наведите для увеличения, перемещайте курсор для осмотра. Уведите курсор, чтобы закрыть. Колесо прокручивает страницу.
Касание
Тап открывает зум внутри кадра. Следующим жестом перемещайте фото, повторным тапом закрывайте. При закрытом зуме работают свайпы галереи и прокрутка страницы.
Клавиатура
Tab — перейти к фото. Enter или Пробел — переключить увеличение. Стрелки — перемещать фрагмент. Esc — закрыть.
08

Частые вопросы

Почему фотография не увеличивается?

Проверьте, что подключён CSS и загружен большой оригинал. Его разрешение должно превышать отображаемый размер фото. Если пикселей недостаточно для увеличения больше 1×, Zoomix оставляет обычную фотографию.

Что произойдёт без большого оригинала?

Zoomix использует выбранный браузером источник превью. Это же происходит при ошибке загрузки data-zoom-src. Увеличение будет доступно, если у превью достаточно пикселей.

Можно ли менять режим после подключения?

При автоматическом подключении меняйте атрибут data-zoomix, предварительно вызвав close(). Настройки конструктора задаются при первом создании: для их изменения вызовите zoom.update({ mode, scale, sideTarget, enabled }).

Почему на телефоне нет бокового окна или лупы?

При сенсорном вводе все режимы используют увеличение внутри кадра. Это позволяет рассматривать детали жестом, не занимая дополнительное место на экране.
